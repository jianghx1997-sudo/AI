# 新AI接手本项目的最短启动说明

## 先记住这一条

这个项目的最高优先级要求是：

**即便开启一个新的对话，或者换一个新的 AI，也必须能立刻按说明稳定产出符合要求的审核稿、本地审核表格和最终图片。**

所以不要依赖：
- 只存在于历史聊天里的口头规则
- “我大概知道用户想要什么”的猜法
- 旧脚本的隐含习惯

## 接手后先做这 5 步

1. 先读 [README.md](E:\AI\know-all\README.md)
2. 再读 [对话式内容生产工作流方案](E:\AI\know-all\docs\对话式内容生产工作流方案.md)
3. 再读 [审核文案与出图统一格式规范](E:\AI\know-all\docs\审核文案与出图统一格式规范.md)
4. 再读 [异常处理规则](E:\AI\know-all\docs\异常处理规则.md)
5. 根据当前任务进入对应 skill
6. 严格按“先审核稿、再本地确认、再出图”的顺序执行

## 当前流程只分三段

### 1. 写作阶段
- 生成审核稿内容
- 只负责内容质量、结构、深度、语气
- 不负责本地文档落盘

### 2. 本地审核文档阶段
- 创建专题文件夹
- 生成或更新 `01_审核稿.xlsx`
- 本地审核表格一旦存在，即成为审核阶段唯一 source of truth
- 刷新 `topic_library_final.xlsx` 超链接

### 3. 出图阶段
- 读取已确认的本地审核表格
- 生成 `02_approved-note-pack.json`
- 生成封面和知识卡图片
- 不负责回改文稿
- 默认沿用固定模板参数，而不是临场重做一套新版式

## 一条最重要的流程线

1. 用户给话题
2. 先生成审核稿
3. 落本地 `01_审核稿.xlsx`
4. 用户直接修改本地审核表格
5. 用户明确确认“文稿无误”或“可以出图”
6. 从本地审核表格读取内容
7. 生成 `02_approved-note-pack.json`
8. 再生成最终图片

## 本地审核 xlsx 的唯一允许实现

本地审核文档只能通过下面这条链路生成：

`UTF-8 结构化源文件 -> tools/write_review_xlsx.py -> outputs/YYYYMMDD_话题/01_审核稿.xlsx`

不要再使用：
- shell 内联大段中文和 emoji 直接拼审核文档
- 专题专用临时脚本当默认入口

## 只剩 30 秒时，至少记住这 4 句

1. 先写审核稿，不直接出图。
2. 审核稿必须先落本地文稿。
3. 本地文稿确认后，才允许进入出图。
4. 长期规则必须写回 skill 和仓库文档。
