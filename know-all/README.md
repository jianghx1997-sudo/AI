# 每日闲聊语料库

当前项目已正式从“独立产品开发”调整为“对话式内容生产工作流”。

## 新定位

这个项目不再继续做成需要单独部署、单独配置 API、单独维护前后端的产品。

新的目标是：

- 以对话方式直接完成每篇小红书笔记生产
- 复用已经沉淀好的内容规范、研究方法、QA 标准和 skill 体系
- 把项目价值放在“方法、规范、工作流”，而不是产品外壳

## 当前保留内容

仓库现在主要保留三类资产：

1. 项目原始规划资料
2. 内容规范与工作流说明
3. prompt / QA 规则等可复用参考资产

## 推荐工作方式

以后使用这个项目时，优先采用下面这条流程：

1. 给出一个话题
2. 由对话完成研究、写稿、审稿、改稿
3. 需要时继续补充图片生成提示或卡片排版建议
4. 通过人工确认得到最终可发布内容

- `config/prompts/research.json`
- `config/prompts/writing.json`
- `config/qa/rules.json`

## 已移除内容

以下内容因“产品化”方向暂停，已视为冗余并清理：

- 前端页面代码
- 后端 HTTP 服务代码
- 模型接入运行时代码
- 本地构建产物
- Node 依赖与工程脚手架
- 网页联调产物和临时日志
- 历史运行输出目录

## 后续建议

后续重点不再是继续开发系统，而是继续沉淀：

- 选题研究方法
- 写作规范
- QA 标准
- skill 体系
- 对话式提需求模板
